# Dots

Curated user configuration for the current Omarchy setup.

Tracked configuration:

- Hyprland and Omarchy shell
- Neovim (`vim.pack`), Herdr, Sesh, WezTerm, and Zsh
- Git
- Aerospace, Karabiner, and Tuxedo placeholders for cross-platform use

Run `./install.sh` to back up conflicting files and link this repository into
`$HOME` and `~/.config`.

Runtime state, logs, secrets, and migration backups are ignored.
